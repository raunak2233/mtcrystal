## 🎨 Design Patterns

### Product Card
```
┌──────────────┐
│              │
│    Image     │  ← Hover: Scale up
│              │  ← Badge: "Best Seller" / "New"
├──────────────┤
│ Product Name │  ← Hover: Purple color
│ Description  │
│ ₹999  [Add] │  ← Add to Cart button
└──────────────┘
```

### Navigation Flow
```
Home → Products → Product Detail → Cart → Checkout
  ↓       ↓
Benefits  Gallery
  ↓       ↓
Contact   Testimonials
  ↓
About
```

## 📱 Responsive Behavior

### Desktop (>1024px)
- 4 products per row
- Full header with all elements
- Category bar visible
- Sidebar layouts

### Tablet (768px - 1024px)
- 3 products per row
- Condensed header
- Category bar visible
- Stacked layouts

### Mobile (<768px)
- 1-2 products per row
- Hamburger menu
- Search below header
- Single column layouts
